# craft-lab

## Getting started

```sh
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` — start the dev server
- `pnpm build` — type-check and build for production
- `pnpm preview` — preview the production build
- `pnpm lint` — run oxlint

## Structure

- `src/recipes/index.ts` — registry of recipes (`{slug, title, description, Component}`)
- `src/recipes/<name>/` — one folder per recipe, each exporting a component
- `src/routes/` — file-based routes (`@tanstack/react-router`):
  - `__root.tsx` — root layout (`<Outlet />` + devtools)
  - `index.tsx` — table of contents at `/`, rendered from the registry
  - `recipes.$slug.tsx` — generic route at `/recipes/$slug` that loads a recipe by slug and renders it (or a not-found view)
- `src/routeTree.gen.ts` — auto-generated by the TanStack Router Vite plugin whenever `vite` runs (`dev`/`build`); never edit by hand. It's committed (per the [TanStack Router FAQ](https://tanstack.com/router/latest/docs/faq)) so `tsc` can type-check a fresh clone, and it's excluded from oxlint/oxfmt

To add a new recipe: build the component under `src/recipes/<name>/`, then add one entry to `src/recipes/index.ts`. No routing or TOC changes needed.
